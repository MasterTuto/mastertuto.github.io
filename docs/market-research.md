blogs e agências são estimativas de mercado, não dados oficiais.

## 1. Perfil (o que dá para vender)

Engenheiro full stack sênior (5+ anos): TypeScript, Node.js, Angular, AWS serverless (Lambda, API
Gateway, EventBridge, Cognito, S3, CloudFormation), PostgreSQL/DynamoDB, WebSockets, IA em produção
(orquestração, streaming, agentes), modernização JSP → Angular, geração de PDF, OWASP. Produtos
próprios: jingle.ia.br (SaaS de IA com assinaturas), ferramentas e jogos neste site.
Diferencial de venda: **entregar a solução escondendo a tecnologia** para quem só quer o resultado.

## 2. Mercado 2026

- Agentes de IA são a prioridade nº 1: 53% dos executivos citam IA generativa/agentes (ABES/IDC);
  40% das empresas já investem; Gartner coloca agentes como tendência central.
- TI cresce ~5,3% em 2026 (ABES/IDC); Hosting & Infra +18,1%; cibersegurança ~R$ 104,6 bi.
- Busca por profissionais com IA +306% (Gupy). Demanda por quem cria agentes com Python e **n8n**.
- Nos marketplaces (99Freelas, Workana) os projetos mais disputados são **automação + WhatsApp + IA +
  CRM** (100–170 propostas por projeto).
- Ferramentas (Stack Overflow 2026): JavaScript 62%, SQL 58%, Python 58%, TypeScript 44%, PostgreSQL
  58%, Node 46%, React 42%; VS Code 71%; Cursor é o editor de IA mais usado (15%); Claude Code é o
  agente de código mais citado, à frente do Copilot.
- Busca: AI Overviews do Google em ~48% das buscas rastreadas (BrightEdge, fev/2026) → GEO/AEO
  virou serviço separado de SEO.

conta da AWS sem explicação · sistema legado que ninguém mexe · carrinho abandonado · MVP que nunca
vai ao ar.

## 6. Como agências e devs convertem (aplicado nas páginas)

- Intenção comercial: "criação de site", "landing page", "quanto custa um site", "contratar
  programador", "automação WhatsApp", "chatbot com IA", "sistema sob medida", "<serviço> + <cidade>",
  "perto de mim". Palavra-chave no H1, H2, URL e meta descrição (≤ 145 caracteres).
- Uma página por serviço (e por nicho), um objetivo e um CTA por página; CTA visível sem rolar.
- Hero com problema antes da solução; prova (números, cases) perto da decisão.
- Preço inicial visível ("a partir de") filtra lead e aumenta confiança.
- Formulário curto (3–4 campos) que já qualifica: aqui, direto para o WhatsApp com mensagem pronta.
- FAQ com dados estruturados (FAQPage), Service/Offer em JSON-LD, links internos entre serviços.
- Mobile first (mais da metade do tráfego) e velocidade (< 1 s na primeira dobra).
- Para IA: conteúdo citável, autoria clara, `llms.txt`, Bing Webmaster Tools.
